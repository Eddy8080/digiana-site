# digiana-site

Site institucional da Digiana.

## Estrutura do Projeto
- `index.html`: Página principal com estilos e scripts embutidos.
- `politica-de-privacidade.html`: Política de privacidade.
- `LEIA-ME-PUBLICACAO.md`: Guia de publicação e documentação de integração.
- `Dockerfile` & `docker-compose.yml`: Configuração para execução em contêiner Nginx local.

## Execução Local via Docker
```bash
docker compose up -d
```
Acesse [http://localhost:8088](http://localhost:8088).
